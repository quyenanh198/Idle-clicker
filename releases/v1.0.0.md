# Dunegear v1.0.0 — Pixel Frontier

First playable release of the Pixel Frontier gear battler.

## Highlights

- Original pixel-art frontier scenery, infantry, outpost and enemy fort.
- Walk/attack sprite animations with hit feedback, projectiles, sparks, smoke and furnace light.
- A 6×4 engine grid with equal-size gears, visible shafts and opposite rotation for connected neighbors. Disconnected gears stop.
- Drag/tap placement, matching-gear merges, automatic lane combat and tap attacks.
- Ten-wave stages, boss encounters, permanent skills, crew cards and recruitment.
- Browser saves, offline rewards, keyboard controls and reduced-motion support.
- Responsive desktop and mobile layouts.

## Download and play

1. Download **dunegear-v1.0.0.zip** below (the playable build, not the automatic source archive).
2. Extract the ZIP and open **index.html** in a modern browser, or serve the extracted folder with any static web server.
3. Recruit a fighter gear next to a golden drive and press **FIGHT**.

Save data belongs to the browser and origin used to play; opening the game from a different location may use a different save. Optional web fonts fall back to local fonts when offline.

## Verification

The release workflow builds the static game and runs all 14 unit/build tests plus 9 Chromium browser tests against the built artifact before publication. A SHA-256 checksum is provided beside the ZIP.
